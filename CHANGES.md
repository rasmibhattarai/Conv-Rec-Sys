## Changes Based on Feedback

**Feedback:** They should give the user the option to review the parameters since they are very subjective.

**Response:** I have incorporated this feedback by developing a user interface where selected parameters are displayed to the user in a sidebar, providing full visibility into the current preference state.

---

**Feedback:** The poster is also too full. It should omit some details and focus more on giving a high level overview.

**Response:** I have incorporated this feedback by removing detailed explanations and restructuring the content to focus on providing a high-level overview across three separate posters.

---

**Feedback:** If a user mentions a product or brand the context remembers this (or previous recommendations) which can lead to poisoned recommendations.

**Response:** I have acknowledged this as a limitation and clearly documented it in the poster. I discussed this issue with the project coordinator, but it remains an open challenge for now.

---

**Feedback:** Additionally a of web search that reads product reviews.

**Response:** While I recognize this would be a valuable addition, I decided not to incorporate it because the project uses dummy data and integrating real internet data would add significant complexity. I have noted this as a potential future enhancement.

---

**Feedback:** Their should be a nice user interface and maybe an explanation why which recommendation was made.

**Response:** I have added a user interface with a sidebar that shows current user preferences, which provides transparency into why certain recommendations were made.
